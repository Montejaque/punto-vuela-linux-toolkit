# Puntos Vuela Toolkit

**Puntos Vuela Toolkit** es una aplicación para Linux que reúne herramientas, aplicaciones y recursos del ecosistema Punto Vuela en un único espacio. Permite explorar aplicaciones AppImage, gestionar las que tienes instaladas y acceder a recursos de utilidad.

## Qué ofrece

- **Catálogo de aplicaciones:** descubre aplicaciones, busca por nombre y consulta sus fichas y detalles.
- **Mis aplicaciones:** organiza tus AppImages, ejecútalas, gestiona permisos y comprueba actualizaciones compatibles.
- **Herramientas Punto Vuela:** acceso a utilidades y aplicaciones publicadas en repositorios del proyecto.
- **Banco de recursos:** consulta recursos y contenidos organizados por áreas.
- **Preguntas frecuentes y ayuda:** guías y respuestas para utilizar la aplicación.
- **Contacto y propuestas:** envía sugerencias de aplicaciones y contacta con el equipo.
- **Personalización:** modo claro, oscuro o automático.

## Tecnologías utilizadas

- **Electron**: plataforma utilizada para la interfaz de escritorio multiplataforma.
- **HTML, CSS y JavaScript**: tecnologías para la interfaz y la experiencia de usuario.

## Compatibilidad

- Linux de 64 bits (x86_64).
- Compatibilidad objetivo: Ubuntu 20.04 y posteriores.
- Los requisitos de cada aplicación del catálogo pueden variar según su desarrollador.

## Instalación

1. Descarga la AppImage desde [Releases](https://github.com/Montejaque/punto-vuela-linux-toolkit/releases).
2. En las propiedades del archivo, habilita el permiso para ejecutarlo como programa si fuera necesario.
3. Abre la AppImage para iniciar Puntos Vuela Toolkit.
