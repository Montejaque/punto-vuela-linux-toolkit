V Puntos Vuela Toolkit
Herramienta de uso profesional interno

Un espacio de software para Puntos Vuela.

Puntos Vuela Toolkit es una aplicación de escritorio para Linux creada para facilitar a los Agentes de Innovación Local el descubrimiento, la instalación y la gestión de aplicaciones AppImage.

Consultar el proyecto en GitHubPolítica de privacidad

Qué ofrece

La herramienta reúne en una única interfaz funciones para localizar aplicaciones compatibles y administrar las AppImages del perfil de usuario.

Catálogo de aplicaciones

Explora el catálogo de Puntos Vuela y fuentes comunitarias de aplicaciones para Linux, con búsqueda y fichas informativas.

Biblioteca local

Organiza las AppImages descargadas, ejecútalas, repara permisos y elimina aplicaciones con confirmación.

Gestión desde tu usuario

Las funciones propias de gestión de AppImages se realizan en el espacio del usuario y no requieren privilegios de administrador.

¿A quién va dirigida?

Puntos Vuela Toolkit está destinada al uso profesional interno de los Agentes de Innovación Local (AIL) de los centros de la red Puntos Vuela. No es un servicio público de descarga para la ciudadanía ni un formulario abierto a empresas.

Importante: la disponibilidad de determinadas funciones depende de la versión instalada, de las fuentes externas y de los servicios de terceros. La compatibilidad y las actualizaciones deben comprobarse en cada publicación del proyecto.

Información y contacto

El código fuente, las instrucciones de desarrollo y las novedades del proyecto están disponibles en el repositorio de GitHub. Para cuestiones relacionadas con la herramienta, puede consultarse la información de contacto incluida en las condiciones de uso.
