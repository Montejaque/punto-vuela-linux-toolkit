# Puntos Vuela Toolkit

Centro de aplicaciones Linux desarrollado con Electron, React y TypeScript.

## Funciones
- Catálogo AppImage Community.
- Biblioteca local para instalar, ejecutar, corregir permisos, actualizar cuando hay soporte compatible y eliminar AppImages.
- Herramientas Punto Vuela de repositorios públicos.
- Banco de recursos y FAQs.
- Tema claro, oscuro y automático.
- Contacto y propuestas con selección de centro, revisión del texto y envío por correo o WhatsApp.

## Guía de uso
La guía integrada de ayuda se actualiza con la edición Electron. La guía interactiva con capturas de pantalla se publica en GitHub Pages:
https://montejaque.github.io/punto-vuela-linux-toolkit/

## Compatibilidad
Objetivo Linux x86_64, con especial atención a Ubuntu 20.04 y posteriores. Las AppImages se gestionan en el perfil del usuario. La compatibilidad de cada aplicación depende de sus requisitos y de las dependencias del sistema.

## Desarrollo
Requisitos: Node.js compatible con Electron 43 y npm.
```bash
npm ci
npm run dev
```
