Dudas frecuentes

Antes de instalar

¿Necesito permisos de administrador?

La gestión de AppImages del Toolkit está diseñada para el espacio de usuario y no requiere root para esas operaciones.

¿Todas las AppImages son compatibles?

No. Cada aplicación puede requerir librerías, drivers o versiones de glibc diferentes. Consulta los requisitos del desarrollador.

¿Dónde se descargan las aplicaciones?

Desde las fuentes de sus proyectos, cuando el catálogo identifica una descarga compatible. Toolkit no aloja las aplicaciones de terceros.

¿Cómo reporto una aplicación o problema?

Utiliza la sección de Contacto y propuestas en la aplicación o abre una incidencia en el repositorio de GitHub.
