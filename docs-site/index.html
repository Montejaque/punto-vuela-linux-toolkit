Cómo utilizar la guía

Selecciona una sección en las pestañas para consultar las capturas de la interfaz y seguir las instrucciones. Las imágenes se generan automáticamente en cada publicación a partir de la interfaz web de Electron con datos de demostración, sin información personal ni envíos reales.

Las capturas pueden actualizarse cuando cambie la aplicación.
